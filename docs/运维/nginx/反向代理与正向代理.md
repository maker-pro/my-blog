# 反向代理与正向代理

* 参考
	* [掘金 梁桂钊【Nginx 反向代理详解】](https://juejin.cn/post/6844903446504554504)
	* [知乎 leetoclass【正向代理和反向代理简单解释】市东城的评论](https://zhuanlan.zhihu.com/p/27491745)

* 区别正、反向代理，主要看为谁做代理，为客户端做代理的叫做正向代理；为目标服务器做代理的叫做反向代理。
反向代理和正向代理的区别可以理解为：
	* 正向代理，客户端可以感受到代理服务器的存在。
	* 反向代理，客户端不能感受到代理服务器的存在。

* 反向代理

![1791684017652.jpg](/blog-images/c9d6b2376dd320.jpg)

反向代理（Reverse Proxy）方式是指以代理服务器来接受Internet上的连接请求，然后将请求转发给内部网络上的服务器，并将从服务器上得到的结果返回给Internet上请求连接的客户端，此时代理服务器对外就表现为一个服务器。

> 为什么使用反向代理

	> 1、 可以起到保护网站安全的作用，因为任何来自Internet的请求都必须先经过代理服务器。

	> 2、 通过缓存静态资源，加速Web请求。

	> 3、 实现负载均衡。顺便说下，目前市面上，主流的负载均衡方案，硬件设备有F5，软件方案有四层负载均衡的LVS，七层负载均衡的Nginx、Haproxy等。


* 正向代理

![1791684159092.jpg](/blog-images/faeab350d50491.jpg)

正向代理指的是，一个位于客户端和原始服务器之间的服务器，为了从原始服务器取得内容，客户端向代理发送一个请求并指定目标(原始服务器)，然后代理向原始服务器转交请求并将获得的内容返回给客户端。比如我们想用国内网络访问国外的服务器，但是我们不能直接访问国外的服务器，此时我们有两台服务器，一台国内的，一台国外的。这时候我们可以用我们国内的服务器做为正向代理来访问国外的服务器。
