# Mysql基础知识

数据库三种数据模型：层次，网状，关系
Mysql语句执行顺序：from,where,group by,having,select,order by
数据库三大范式：
* 1.第一范式(1NF):要求每个属性都是原子的，不可再分
* 2.第二范式(2NF):要求表中的每个非主键列都完全依赖于主键列
* 3.第三范式(3NF):要求每个非主键列都不传递依赖于其他非主键列

私网地址是：不能在公网出现，所有路由器不能网目标地址为私网地址的数据报，ABC类各保留3个区域作为私网地址：
* 1.A类地址:10.0.0.0~10.255.255.255
* 2.B类地址:172.16.0.0 ~172.31.255.255
* 3.C类地址:192.168.0.0~192.168.255.255

ROUND(X,D) 可以进行四舍五入，按照对应的位数, (复数四舍五入向下取)

TRUNCATE(X,D) 直接截取，不进行四舍五入

FORMAT(X,D) 会四舍五入，返回类型是字符串，因为满三位会加一个逗号

```
ROUND(1.56) = 2
ROUND(1.27,1) = 1.3
TRUNCATE(1.27,1) = 1.2
FORMAT(10000.1237, 3) = 10,000.124
ROUND(10000.124,3) = 10000.124
```

数据库系统(DBS)由五部分组成：硬件系统、数据库集合、DBMS、及相关软件、数据库管理员与用户；
数据库系统(DBS)通常由以下组成部分构成：

* 1.数据库管理系统(DBMS):DBMS是DBS的核心组件，它管理着整个数据库系统的运行。DBMS负责数据的存储、检索、更新和删除等操作。
* 2.数据模型：数据模型描述了数据库中数据的组织方式和关系。常见的数据模型包括层次结构模型、网状结构模型、关系模型等。
* 3.数据库语言：数据库语言是一种专门用于与DBMS进行交互的编程语言。常见的数据库语言包括SQL、PL/SQL等。
* 4.数据库实例：数据库实例是指一个具体的数据库系统，它包含了一个或多个数据库、一个或多个用户以及相关的应用程序。
* 5.数据库管理员(DBA):DBA是负责管理和维护数据库系统的专业人员，他们负责设计、优化和维护数据库系统，确保其安全、可靠和高效地运行。

### 事务隔离级别
mysql幻读和不可重复读的区别?
> 幻读和不可重复读都是数据库中的并发问题，但它们的区别在于：

* 1.幻读是指在一个事务执行期间，其他事务插入了新的数据行，导致当前事务看到了不同的数据集合。而不可重复读是指在一个事务执行期间，其他事务修改了同一行数据，导致当前事务多次读取到相同的数据。
* 2.幻读是全局性的，即所有涉及到的行都可能被其他事务插入或删除。而不可重复读只会影响到当前事务读取的数据行。
* 3.幻读可以通过锁定整张表或者行来解决，但是这样会阻塞其他事务的执行。不可重复读可以通过加锁来解决，但是会降低并发性能。
* 4.幻读的解决方案包括使用行级锁、使用事务隔离级别为Serializable(串行化)等。不可重复读的解决方案包括使用行级锁、使用事务隔离级别为Read Committed(可重复读)等。

#### 触发器

> 触发器是一种特殊的存储过程，它在插入，删除或修改特定表中的数据时触发执行，它比数据库本身标准的功能有更精细和更复杂的数据控制能力。

注意事项：
* 1.只有表才可以支持触发器，视图和临时表都不支持触发器
* 2.每个表的每个事件只支持一个触发器，因此每个表最多支持6个触发器
* 3.单一触发器不能与多个操作相关
* 4.触发器不能更新和覆盖，如果想更新一个触发器必须先删除，再创建

数据库的特点是数据共享、数据独立、减少数据冗余、避免数据不一致和加强数据保护
