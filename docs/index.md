# 关于 Maker Pro

你好，我是 Joe，一名 PHP 后端开发者。这里是我的个人博客。我把开发时遇到的问题记下来，留给下次碰到同样问题的自己，也分享给正在找答案的人。

有些笔记从一个很小的疑问开始：为什么在月底调用 `strtotime()` 计算下个月，结果会跳过一个月？有些则记录一件事的完整经过，比如怎样把一个 PHP 商城项目打成 Docker 镜像，再部署到 Kubernetes。写这些文章时，我希望把问题出现的条件、当时的思路和用到的代码放在一起，过一阵子再读，还能看懂当初为什么这么做。

工作之外，我也会在这里放几张旅行照片，写下沿途的见闻。欢迎来逛逛。
